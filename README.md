# Excel VBA Purchasing Application

A VBA-based purchasing management application developed to support purchasing data entry, search, validation, record updating, and analysis processes.

## Features

- VBA UserForm-based purchasing interface
- Purchase record creation and updating
- Item number search
- Supplier information management
- Unit price and date validation
- Automatic total price calculation
- Integration with an external Excel data source
- Automatic detection of the external data file
- Portable folder-based structure
- Purchasing data analysis

## Technologies

- Microsoft Excel
- VBA (Visual Basic for Applications)
- Excel UserForms
- Excel Worksheets
- VBA Workbook and Worksheet automation

## Application Structure

The application uses an Excel VBA interface to manage purchasing operations and communicate with an external Excel-based data source.

The VBA application can automatically locate the external data file in the same folder as the main application file.

## Data Privacy

This repository does not contain confidential company data.

All company-specific purchasing records, supplier information, prices, item codes, and internal Excel files have been excluded from the repository.

The project is presented using source code and anonymized/sample data where necessary.

## Project Purpose

This project was developed as part of a software and data analysis internship to gain practical experience in VBA programming, data validation, Excel automation, purchasing processes, and application development.
